# LandingPageAssignment

This is the landing page for my personal portfolio.

A personal portfolio landing page designed to showcase my projects, skills, and contact information.

## About

This is the landing page for my personal portfolio. It serves as the primary entry point for visitors to learn about me, explore my work, and get in touch.

## Features

- Personal introduction and bio
- Showcase of projects and work
- Skills and technologies section
- Contact information
- Links change colors on hover

## Getting Started

### Prerequisites

A modern web browser is all you need to view this page.

### Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/dsfuller4/LandingPageAssignment.git
   ```
2. Open `index.html` in your browser.
